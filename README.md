## ✨ Điểm Nổi Bật (Features)

- **🎨 Thiết Kế Boutique Ấm Cúng**: Phối màu Tone Cà Phê & Gỗ Mộc (`#3E2723`, `#5D4037`, `#FAF8F5`), kết hợp font chữ thanh lịch **Playfair Display** & **Plus Jakarta Sans**.
- **🎤 Hệ Thống Khám Phá Phòng Hát**: Lọc danh mục phòng theo nhóm khách (Tiêu chuẩn 2-4 người, VIP Lounge 5-8 người, Party Suite 8-20 người) cùng thông số âm thanh chi tiết.
- **📸 Góc Photobooth Hàn Quốc**: Trải nghiệm chụp 4 khung hình, xem trước strip ảnh, phụ kiện độc đáo, in ảnh 15s & quét mã QR tải video hậu trường.
- **🧮 Bộ Tính Chi Phí Nhanh (Interactive Pricing Calculator)**: Dự tính chi phí chính xác theo giờ hát, gói combo và photobooth với chiết khấu tự động.
- **📅 Đặt Lịch Hẹn Thông Minh**: Form đặt phòng trực tuyến không cần cọc trước, hiệu ứng pháo hoa chúc mừng (`canvas-confetti`) và xuất mã đặt chỗ ngay lập tức.
- **⭐ Đánh Giá & Góp Ý Khách Hàng**: Khu vực feedback trực quan với thang điểm sao và phản hồi tức thì.
- **📱 Responsive & Tối Ưu Hóa Tối Đa**: Mượt mà trên mọi thiết bị di động, tablet và máy tính để bàn.

## 🛠 Công Nghệ Sử Dụng (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **FX**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Fonts**: Google Fonts (`Playfair Display`, `Plus Jakarta Sans`) via `next/font`

## 🚀 Khởi Chạy Dự Án (Getting Started)

### Cài đặt thư viện:
```bash
pnpm install
```

### Chạy môi trường phát triển (Development):
```bash
pnpm dev
```
Mở trình duyệt tại [http://localhost:3000](http://localhost:3000) để trải nghiệm.

### Đóng gói sản phẩm (Production Build):
```bash
pnpm build
pnpm start
```
