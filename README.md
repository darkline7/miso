# MISO - Musicbox & Photobooth

Website giới thiệu và đặt phòng cho hệ thống phòng hát **MISO Musicbox & Photobooth**.

## ✨ Tính năng nổi bật

- **Giao diện hiện đại**: Thiết kế phong cách ấm cúng (tone màu nâu - kem sang trọng), responsive trên mọi thiết bị.
- **Chương trình khuyến mãi**: Hiển thị combo sinh nhật, happy hour, photobooth check-in.
- **Khám phá không gian**: Gallery hình ảnh hệ thống phòng hát với hiệu ứng mở rộng/thu gọn mượt mà.
- **Bảng giá chi tiết**: Bảng giá theo khung giờ (Tiêu chuẩn, VIP, Party), giá dịch vụ Photobooth, Combo ưu đãi và đồ uống/snack.
- **Form đặt phòng & Feedback**: Modal đặt lịch hẹn thông minh (chọn loại phòng, ngày giờ, số lượng khách) và form gửi góp ý.

## 🛠 Công nghệ sử dụng

- **HTML5**
- **Tailwind CSS** (CDN)
- **Vanilla JavaScript**
- **Google Fonts** (Inter & Playfair Display)

## 🚀 Hướng dẫn mở dự án

Mở trực tiếp file `index.html` trên trình duyệt hoặc sử dụng Live Server trong VS Code:

```bash
# Hoặc chạy một web server tĩnh đơn giản
npx serve .
# Hoặc
python -m http.server 3000
```
